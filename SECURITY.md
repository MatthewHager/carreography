# Security

Carreography is a static site: the song, the listening and the choreography stay in your browser, and there
is no server. The realistic risks are the code and the files the site loads (its dependencies, the models
and assets in the releases).

To report a vulnerability, use GitHub's private reporting: **Security → Report a vulnerability** on this
repository. Please don't open a public issue for it. You'll get an answer as soon as the maintainer can.
